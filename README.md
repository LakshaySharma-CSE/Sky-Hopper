# 🎮 Sky Hopper

<p align="center">
  <img src="Skyhopper.png" alt="Sky Hopper Logo" width="200"/>
</p>

Sky Hopper is a browser-based 2D arcade game built with HTML5 Canvas and JavaScript. It features gravity-based movement, procedural obstacles, collision detection, and real-time scoring. The project demonstrates game loops, basic physics, and interactive UI in a lightweight, responsive environment.

---

## 🛠 Features
- 🎮 Smooth gravity-based movement  
- 🚧 Randomly generated obstacles  
- 💥 Collision detection system  
- 📊 Real-time score tracking  
- 🔁 Restart functionality  
- ⌨️ Keyboard (Space) + Button controls  
- 💾 High score saved in browser  

---

## 🎮 Controls
- ⌨️ Press **SPACE** to jump  
- 🖱️ Click **JUMP** button  
- 🔄 Click **RESTART** to play again
